V11 CERTIFICATE VAULT
=====================
Place the real certificate files in this folder and keep the filenames referenced by index.html.

Supported:
- PDF
- JPG / JPEG
- PNG
- WEBP

Recommended filenames:
ceh.pdf
cpsp.pdf
csocp.pdf
cwasp.pdf
iso-27001-lead-auditor.pdf
mcitp.pdf
cybersecurity-masters.pdf
cloud-essentials.pdf
cissp-training.pdf
cloud-security-professional-training.pdf

After adding a certificate, update the matching data-cert path in index.html.
The V11 viewer opens PDFs in a new browser tab and images in a full-screen modal.
For a real GitHub Pages deployment, certificate files must be committed to the repository under assets/certificates/.
