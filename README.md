# Karthikeyan M — Cybersecurity Portfolio V9 Fixed

Fresh GitHub Pages package based on the V7 visual direction with the requested V9 enhancements.

## Deployment-safe structure
- `index.html` is at repository root.
- CSS: `assets/css/style.css`
- JavaScript: `assets/js/main.js`
- Icons: `assets/icons/`
- `.nojekyll` is included for static-site safety.
- GitHub Pages workflow: `.github/workflows/pages.yml`

## Publish
1. Create a fresh GitHub repository.
2. Upload the contents of this folder directly to the repository root.
3. Keep the default branch as `main`.
4. Repository Settings → Pages → Source → GitHub Actions.
5. Push/commit the files and wait for the Pages workflow to complete.
6. Open the Pages URL.

The decorative cyber animations are visual simulations only; they are not live SOC/SIEM feeds.
